Put the Vazirmatn font files here (SIL OFL, free): Vazirmatn-Regular.ttf, Vazirmatn-Medium.ttf,
Vazirmatn-SemiBold.ttf, Vazirmatn-Bold.ttf  (https://github.com/rastikerdar/vazirmatn  -> fonts/ttf).
The app loads them automatically; without them it falls back to the Google Fonts provider, then the system font.

Tip: run `sh scripts/fetch-fonts.sh` from the project root to download them.
